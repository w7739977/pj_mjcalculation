# 测试指南

本文档说明如何测试川麻记账小程序。

## 🎯 测试方案

### 方案一：本地测试（推荐先这样）

**适用场景：** 没有云开发环境，只想看页面效果

**步骤：**

1. **下载微信开发者工具**
   - 论达: https://developers.weixin.qq.com/miniprogram/devtools/download.html
   - 选择对应系统版本（Windows/Mac/Linux）

2. **导入项目**
   - 打开微信开发者工具
   - 选择"导入项目"
   - 目录选择: `/path/to/pj_mjcalculation/miniprogram`
   - AppID填写: `test123` (测试号)
   - 点击"导入"

3. **切换到测试页面**
   - 在开发者工具中,修改 `app.json`:
     ```json
     "pages": [
       "pages/test/test",  // 添加这一行
       "pages/index/index",
       "pages/confirm/confirm",
       "pages/settle/settle",
       "pages/history/history"
     ]
     ```
   - 保存后编译器会自动跳转到测试页面

4. **测试功能**
   - ✅ 测试语音识别: 点击"测试语音识别"按钮
   - ✅ 测试AI解析: 点击"测试AI解析"按钮
   - ✅ 完整流程: 点击"完整流程测试"按钮

---

### 方案二：云开发环境测试

**适用场景:** 需要完整功能测试（语音+AI）

**前置条件:**
- 微信开发者工具
- 微信小程序账号（个人/企业）
- 讯飞API密钥（可选）
- Claude API密钥（可选）

**步骤:**

1. **开通云开发**
   - 在开发者工具中点击"云开发"
   - 选择"开通"
   - 环境名称: `mj-calculation`
   - 选择免费版（基础版1）

2. **创建数据库集合**
   - 点击"数据库"
   - 创建集合:
     - `sessions` - 对局记录
     - `debts` - 欠账记录
     - `players` - 玩家信息

3. **部署云函数**
   ```bash
   # 在云开发控制台
   右键 cloudfunctions/voiceToText → 上传并部署: 云安装依赖
   右键 cloudfunctions/aiParser → 上传并部署: 云安装依赖
   ```

4. **配置环境ID**
   - 复制云开发环境ID
   - 修改 `miniprogram/app.js`:
     ```javascript
     wx.cloud.init({
       env: '你的环境ID',  // 替换这里
       traceUser: true
     })
     ```

5. **配置API密钥**
   - **讯飞语音API**:
     - 注册: https://www.xfyun.cn/
     - 修改 `cloudfunctions/voiceToText/index.js`:
       ```javascript
       const appId = '你的AppID'
       const apiKey = '你的APIKey'
       const apiSecret = '你的APISecret'
       ```
   
   - **Claude API**:
     - 注册: https://console.anthropic.com/
     - 修改 `cloudfunctions/aiParser/index.js`:
       ```javascript
       const apiKey = '你的Claude API密钥'
       ```

## 🔧 常见问题

### Q: 编译报错 "云开发环境未初始化"
**A:** 在 `app.js` 中检查 `wx.cloud.init()` 是否正确配置

### Q: 语音识别失败
**A:** 检查讯飞API密钥配置, 或使用本地测试模式

### Q: AI解析返回错误
**A:** 检查Claude API密钥配置, 或使用本地测试模式

### Q: 数据库操作失败
**A:** 检查云开发环境是否开通, 数据库集合是否创建
